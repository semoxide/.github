# .github

Organization-wide configuration for the [semoxide](https://github.com/semoxide) repositories.

- `renovate/default.json`: shared [Renovate](https://docs.renovatebot.com/) preset; each repo's `renovate.json` extends `github>semoxide/.github:renovate/default`.
